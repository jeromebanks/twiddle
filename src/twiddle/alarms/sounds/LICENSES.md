# Alarm sound licences

Each file is 45 s of mono MP3 at 48 kbps. Four are generated here; one is a
CC0 recording. A recorded sound may be added only with its page, author,
licence (CC0 or public domain, as that page states it) and retrieval date in
this table.

| File | Sound | Source | Licence |
|---|---|---|---|
| `bell.mp3` | Classic bell | generated by `twiddle.tone.classic_bell` | generated here, no third-party material (this repo's MIT licence) |
| `beep.mp3` | Digital beep | generated by `twiddle.tone.digital_beep` | generated here, no third-party material (this repo's MIT licence) |
| `rise.mp3` | Gentle rise | generated by `twiddle.tone.gentle_rise` | generated here, no third-party material (this repo's MIT licence) |
| `chimes.mp3` | Chimes | generated by `twiddle.tone.chimes` | generated here, no third-party material (this repo's MIT licence) |
| `birdsong.mp3` | Birdsong | recording "Waidachswald Oberschefflenz Abend 20250616 2005.ogg" by Evillan (Wikimedia Commons user Karlunun), recorded 2025-06-16: <https://commons.wikimedia.org/wiki/File:Waidachswald_Oberschefflenz_Abend_20250616_2005.ogg>, retrieved 2026-10-06 | CC0 1.0 (public domain dedication, as the file page states) |

Regenerate the four with `uv run python tools/make_alarm_sounds.py`. The
recording is trimmed (45 s from 0:05, 1 s fade in, 2 s fade out) and encoded with
`uv run python tools/make_alarm_sounds.py --recording <the downloaded .ogg>`.
Both need `ffmpeg`.
