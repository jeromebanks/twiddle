# Alarm sound licences

Every file here is synthesised from sine waves by `tools/make_alarm_sounds.py`:
no recording, sample or third-party material. The author dedicates each to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Regenerate them with `uv run python tools/make_alarm_sounds.py` (needs `ffmpeg`).

| File | Sound | Source | Licence |
|---|---|---|---|
| `bell.mp3` | Classic bell | generated (`classic_bell`) | generated, CC0 |
| `beep.mp3` | Digital beep | generated (`digital_beep`) | generated, CC0 |
| `rise.mp3` | Gentle rise | generated (`gentle_rise`) | generated, CC0 |
| `birdsong.mp3` | Birdsong | generated (`birdsong`) | generated, CC0 |
| `chimes.mp3` | Chimes | generated (`chimes`) | generated, CC0 |

A recorded sound may be added only with its page, author, licence (CC0 or
public domain, as that page states it) and retrieval date in this table.
